# Retail Sales Data Analysis & Business Insights

## 📌 Project Overview

This project was completed as part of the QSkill Data Science Internship.

The objective of this project is to analyze retail sales data using Python and identify meaningful business insights related to sales, profit, quantity, customers, products, categories, regions, and customer segments.

The project includes data cleaning, exploratory data analysis (EDA), visualization, trend analysis, and business insights.

---

## 🎯 Objectives

- Load and clean the retail sales dataset using Pandas.
- Handle inconsistent data formats and duplicate records.
- Perform exploratory data analysis.
- Analyze sales, profit, quantity, and customer-related statistics.
- Analyze product, category, customer, and regional performance.
- Identify trends and patterns in sales and profitability.
- Create meaningful visualizations using Matplotlib and Seaborn.
- Derive useful business insights from the analysis.
